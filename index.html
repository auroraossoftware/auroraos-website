Engineering Foundation

Linux underneath. Pure stability.

We did not attempt to build a custom kernel from scratch. Linux already provides three decades of engineering in process management, filesystems, hardware drivers, and memory security.

  • Total hardware compatibility: Runs on laptops, desktops, and workstations effortlessly.
  • Standard desktop software: Run Steam, Flatpak, Docker, VS Code, and standard Linux apps natively.
  • Modern POSIX userspace: Built around systemd, standard POSIX APIs, and open standards.

Questions & Answers

Frequently Asked Questions

Clear answers regarding Aurora OS architecture, privacy principles, compatibility, and licensing.

Is Aurora OS an entirely new kernel or a Linux distribution?

Aurora OS is built directly on top of the standard Linux 6.x kernel. We intentionally chose Linux rather than engineering a kernel from scratch to preserve three decades of battle-tested driver compatibility, robust POSIX file systems, and hardware support across laptops, desktops, and workstations.

Aurora’s innovation lives in its userspace: the lightweight aurora-ai system daemon, hardware-isolated sandboxing, and unified desktop intelligence.

How does Aurora OS protect privacy? Does my data leave my machine?

Privacy in Aurora OS is an architectural guarantee, not merely a policy statement. All conversational contexts, tool invocation parameters, and vector search embeddings reside strictly on your local hardware.

The system daemon operates inside a constrained Linux sandbox using Landlock and seccomp filters. No background telemetry or unsolicited phone-home connections are ever made without explicit, interactive authorization.

Can I run standard Linux software, Steam games, and developer tools?

Yes, 100%. Because Aurora OS is built on the Linux kernel with standard POSIX libraries and Wayland/X11 display protocols, everything you expect on a Linux workstation runs seamlessly out of the box:

  • Productivity & Browsers: Chrome, Firefox, LibreOffice, Slack, Discord.
  • Developer Toolchains: VS Code, Neovim, Docker, Podman, Rust, Python, Go, Node.js.
  • Gaming & Media: Steam, Proton, Lutris, OBS Studio, Blender.
What are the minimum hardware requirements?

Aurora’s core daemon is written in safe Rust with an idle resident memory footprint under 3 MB, meaning it introduces virtually zero overhead to the OS.

  • Base OS: Any modern 64-bit x86_64 or aarch64 processor, 4 GB RAM, 20 GB storage.
  • Local AI Acceleration (Optional): For on-device LLM inference (e.g. 7B/8B models), an integrated NPU or discrete GPU with 8 GB+ VRAM (NVIDIA CUDA, AMD ROCm, or Intel Vulkan) is recommended.
How does Aurora prevent AI agents from harming my files?

We leverage kernel-grade isolation rather than relying on software prompts. All filesystem interactions run through Linux openat2 with RESOLVE_BENEATH and RESOLVE_NO_SYMLINKS flags, making directory escape attacks impossible.

Additionally, tool invocations require deterministic policy evaluation (evaluated in just 0.141 ms), preventing unintended mutations to root or system directories.

Is Aurora OS open source, and how can I contribute?

Aurora OS is entirely free and open-source software licensed under the MIT License. All codebase development, architectural decision records (ADRs), and performance benchmarks are hosted on GitHub.

You can clone the repository, run the test suites with cargo test, submit pull requests, or participate in discussions on the Aurora OS GitHub Repository.
